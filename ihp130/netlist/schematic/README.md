# Schematic Netlists

Schematic netlists of `tinywhisper_top` for LVS, exported from Xschem.

They are written by `make klayout-lvs-netlist` (CDL, `tinywhisper_top_klayout.cdl`) and by `make magic-lvs-netlist` (SPICE, `tinywhisper_top_magic.spice`). Both targets also run as the first step of `make klayout-lvs` and `make magic-lvs`.

This folder stays empty until the top-level LVS netlist export is run. See [Layout Versus Schematic (LVS)](../../README.md#layout-versus-schematic-lvs--design-rule-check-drc) in the top-level README.
